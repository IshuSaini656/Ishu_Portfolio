# 💼 Ishu Saini Portfolio

A modern, responsive, single-page portfolio built with React and Tailwind CSS to showcase my projects, skills, and experience.

## 🚀 Live Demo

🌐https://ishu-portfolio-five.vercel.app/

## ✨ Features

- Responsive design (Mobile, Tablet & Desktop)
- Modern dark UI
- Smooth scrolling navigation
- Project showcase with image slider
- Contact form with EmailJS
- Google reCAPTCHA protection
- Resume download
- Social media links
- Error Boundary
- Lazy-loaded project images
- SEO optimized

---

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

### Libraries

- React Scroll
- EmailJS
- Google reCAPTCHA
- Lucide React
- Sonner

## ⚙️ Installation

```bash
git clone https://github.com/yourusername/portfolio.git

cd portfolio

npm install

npm run dev
```

---

## 📦 Build

```bash
npm run build
```

## 🔒 Environment Variables

Create a `.env` file.

```env
VITE_EMAIL_SERVICE_ID=
VITE_EMAIL_TEMPLATE_ID=
VITE_EMAIL_PUBLIC_KEY=
VITE_RECAPTCHA_SITE_KEY=
```
